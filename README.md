# 所谓伊人在何方

个人生活博客，记录日常、旅行与生活感悟，使用 Hexo 构建。

线上地址：[blog.charlestang.org/extmem](https://blog.charlestang.org/extmem/)。

## 本地构建与预览

使用 Node.js 24 和 pnpm 10.30.3，在项目目录运行：

```sh
pnpm install --frozen-lockfile
pnpm run build
pnpm run server --ip 127.0.0.1 --port 4000
```

本地预览：[http://127.0.0.1:4000/extmem/](http://127.0.0.1:4000/extmem/)。
